# Text Classifier LLM Demo

[![Packaged with KitOps](https://img.shields.io/badge/Packaged%20with-KitOps-FFAF52?labelColor=363636)](https://kitops.org)

A complete end-to-end demo showcasing fine-tuning a T5 language model for text classification using LoRA (Low-Rank Adaptation) and deploying it as a FastAPI service with Kubernetes support.

## 🚀 Quick Start

### Prerequisites
- Python 3.8+
- pip
- Docker (for containerization)
- Kubernetes cluster (optional, for deployment)

### Installation & Training

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Train the model:**
   ```bash
   python src/train.py
   ```
   This will:
   - Load the training data from `data/tiny.csv`
   - Fine-tune a Flan-T5-small model using LoRA
   - Save the model to `fine-tuned/` directory

3. **Start the API server:**
   ```bash
   python src/app.py
   ```
   The API will be available at `http://localhost:8000`

### Testing the API

#### Text Generation
```bash
curl -X POST "http://localhost:8000/generate" \
     -H "Content-Type: application/json" \
     -d '{"text": "Translate to French: I love ML"}'
```

#### Health Check
```bash
curl "http://localhost:8000/health"
```

## 🏗️ Architecture

### Model Architecture
- **Base Model**: Google Flan-T5-small (80M parameters)
- **Fine-tuning Method**: LoRA (Low-Rank Adaptation)
- **Task**: Text-to-text generation
- **Training Data**: 20 prompt-answer pairs

### API Architecture
- **Framework**: FastAPI
- **Endpoints**:
  - `POST /generate` - Text generation
  - `GET /health` - Health check

### Kubernetes Deployment
- **Replicas**: 1
- **Init Container**: KitOps init container for model loading
- **Model Path**: `/model` (populated by kitops-init)
- **Health Checks**: Readiness probe

## 🔧 Configuration

### Training Parameters
- **Epochs**: 1
- **Batch Size**: 4
- **FP16**: False
- **BF16**: False
- **Output Directory**: ft-run

### LoRA Configuration
- **Rank (r)**: 8
- **Task Type**: SEQ_2_SEQ_LM

## 🐳 Docker & Kubernetes

### Using KitOps

#### Package & Push
```bash
kit init .                                  # only first time
kit pack . -t jozu.ml/<user>/text-classifier:0.1.0
kit push    jozu.ml/<user>/text-classifier:0.1.0
```

#### Deploy to Kubernetes
```bash
# Apply the Kubernetes manifests
kubectl apply -f k8s/

# Check deployment status
kubectl get pods -l app=text-classifier

# Port forward for testing
kubectl port-forward service/text-classifier 8000:80
```

## 📊 Model Performance

The model is trained on a small dataset for demonstration purposes. In production, you would want to:

1. **Expand the dataset** with more diverse examples
2. **Add validation data** for proper evaluation
3. **Implement cross-validation** for robust performance metrics

## 🛠️ Development

### Adding New Training Data
1. Add new rows to `data/tiny.csv`

3. Restart the API: `python src/app.py`

### Modifying the Model
- Change base model in `src/train.py`
- Adjust LoRA parameters in `create_model_and_tokenizer()`

### Extending the API

## 🚨 Troubleshooting

### Common Issues

1. **Model not found error**
   - Ensure you've run `python src/train.py` first
   - Check that `fine-tuned/` directory exists

2. **CUDA out of memory**
   - The model uses CPU by default
   - If using GPU, reduce batch size in training

3. **Port already in use**
   - Change port in `src/app.py` or kill existing process
   - Use `lsof -i :8000` to find process using port 8000

4. **Kubernetes deployment fails**
   - Check pod logs: `kubectl logs <pod-name>`
   - Verify KitOps model is pushed: `kit list`
